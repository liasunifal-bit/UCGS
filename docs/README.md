# Documentação UCGS (Unidade de Cuidados e Gestão em Saúde)

Este diretório contém a documentação técnica e de contexto para o ecossistema UCGS, auxiliando na manutenção, escalabilidade e futura modularização do sistema.

## 🗂️ Conteúdo

- [**Contexto: Painel de Controle**](contexto-painel-controle.md): Especificações técnicas da página principal, incluindo autenticação, sistema de design e componentes.

## 🏗️ Visão Geral do Sistema

O UCGS é um sistema de gestão clínica modular, atualmente operando com um frontend monolítico de alta densidade e integração robusta com o Supabase para persistência de dados e autenticação.
