## 📋 Tipos de Posts por Objetivo

### 🚀 **Para Vendas/Conversão**

```
Elementos Essenciais:
├─ CTA claro ("COMPRE", "SAIBA MAIS")
├─ Desconto/Oferta destacada
├─ Foto do produto em alta qualidade
├─ Preço em destaque
├─ Data limite de validade
└─ Link de compra fácil de encontrar

Cores: Verde (ação), Laranja (urgência), Branco
Tipografia: Grande para CTA, médio para detalhes
Exemplo: Post de produto com 40% off
```

### 📚 **Para Educação/Informação**

```
Elementos Essenciais:
├─ Título claro e descritivo
├─ Passos numerados (máx 5-6)
├─ Ícones ilustrando cada ponto
├─ Dados ou estatísticas
├─ Conclusão clara
└─ Fonte para mais info

Cores: Azul (confiança), Verde (aprendizado), Branco
Tipografia: Títulos bold, corpo regular
Exemplo: Tutorial de 5 passos, Infográfico
```

### 💬 **Para Engajamento/Comunidade**

```
Elementos Essenciais:
├─ Pergunta clara
├─ Opções visuais
├─ Espaço para comentários
├─ Tema relevante à audiência
├─ Emojis apropriados
└─ Call para comentar/compartilhar

Cores: Vibrante (atração), Neutro (legibilidade)
Tipografia: Pergunta grande, opções médias
Exemplo: "Qual é seu favorito?", Votação
```

### 🎁 **Para Promoção/Ofertas**

```
Elementos Essenciais:
├─ Desconto em destaque
├─ Imagem do produto
├─ "OFERTA LIMITADA" ou urgência
├─ Quantidade limitada (se aplicável)
├─ Data de término
├─ Botão de ação forte

Cores: Vermelho (urgência), Ouro (exclusividade)
Tipografia: Desconto gigante, outros menores
Exemplo: "50% OFF", "Últimas unidades"
```

## 🎬 Processo de Criação Passo a Passo

### 1️⃣ **Defina o Objetivo**
```
Pergunta: O que quero que o post faça?
├─ Vender algo?
├─ Educar sobre algo?
├─ Gerar engagement?
├─ Divulgar marca?
└─ Outras ações?
```

### 2️⃣ **Escolha a Inspiração**
```
Use a galeria para encontrar:
├─ Categoria (Instagram, LinkedIn, TikTok)
├─ Mood (energético, calmo, profissional)
├─ Tipo (tutorial, pôster, infográfico)
└─ Exemplo visual de inspiração
```

### 3️⃣ **Adapte às Cores da Marca**
```
Pegue a paleta da inspiração e:
├─ Mantenha 60% da cor primária
├─ Use 30% da cor secundária
├─ Destaque com 10% da cor terciária
└─ Sempre considere contraste
```

### 4️⃣ **Defina a Hierarquia Visual**
```
Ordem de importância:
1. Imagem/Visual Principal
2. Título/Mensagem Única
3. Subtítulo/Detalhes
4. CTA ou Informação Secundária
5. Logo/Branding
```

### 5️⃣ **Crie com a Skill**
```
Use design-automation para gerar:
prompt = inspiracao_galeria.get_inspiration_prompt(inspiracao_id)
result = client.generate_poster(
    prompt=prompt,
    output_path="meu_post.png",
    steps=40,
    guidance=3.8
)
```

### 6️⃣ **Refine e Versione**
```
Crie múltiplas versões:
├─ v1: Versão original
├─ v2: Com ajustes de feedback
├─ v3: Com variações de cores
├─ Escolha a melhor
└─ Finalize para publicação
```

## 💡 Dicas de Ouro para Posts Incríveis

### ✅ FAÇA:
- Use espaço em branco estrategicamente
- Tenha contraste forte entre texto e fundo
- Escolha no máximo 2 fontes diferentes
- Use máximo 3 cores primárias
- Teste em dispositivo móvel
- Inclua CTA quando relevante
- Mantenha consistência visual

### ❌ EVITE:
- Texto muito pequeno (<14px)
- Muitos elementos competindo por atenção
- Cores que não combinam
- Imagens pixeladas ou desfocadas
- Fontes ilegíveis
- Poluição visual
- Posts sem propósito claro
